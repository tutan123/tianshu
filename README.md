# 天枢 · 重返江大 | Web Demo 3.0

## 开始试玩

在 Chrome 或 Edge 中打开本目录的 `index.html`。这是纯静态离线页面，不需要安装依赖、构建或运行服务器。也可直接双击 `开始游戏.cmd`。进度保存在该浏览器的本地存储中，更换浏览器前可在“存档”面板导出 JSON。

## 本版可玩内容

- 10 个主线、4 个支线，完整首章与三个结局条件。
- Three.js 三维校园：宿舍、钟楼、图书馆、镜湖、球场、计算机学院、后街与中央广场。
- 校园全景与近距离步行模式，同一校园场景切换镜头；目前没有独立可进入的室内地图。
- WASD / 方向键移动、拖动旋转镜头、滚轮及按钮缩放，点击地面移动。点击移动采用直线追踪和碰撞，复杂障碍前需手动绕行。
- 走近可用事件按 E 或点击右下角事件按钮；“校园全景”和底部“校园”均可返回全景。触屏可用左下方向按钮移动。
- 三维俯视小地图、玩家标记、事件光环、天气切换、雨粒、湖面波动、学生行走、夜间窗灯。
- 视频/静帧剧情、选项、认知问答、QTE、电路取证，以及三张固定行动卡构成的回合对决。
- 三项模块升级、人物关系、手机消息、剧情回顾、自动存档和三槽手动存档。
- 中途刷新保留镜头、题目、已购买提示、电路位置、战斗血量与行动力。导入损坏进度会被拒绝，当前存档保留。

- `node --test tests/state.test.cjs`：12 项通过。
- Playwright 浏览器验收：54 项检查通过，全部 14 个节点通过真实按钮完成，获得“破晓之人”结局。
- 完成 1440×960 桌面、390×844 移动端检查，验证 3D 移动、碰撞、缩放、雨天、附近交互、返回全景、三类挑战刷新和手动读档。
- 检查 WebGL 画布像素存在不同颜色；地图实际渲染，无未捕获页面错误。
- 缺少 Three.js 时回退到可进入剧情的插画地图。
- 额外验证 360×740 手机端三张战术卡没有文字横向溢出且可出牌；五段本地 MP4 均成功解码为 1280×720，readyState=4。

原始记录：`tests/browser-results.json`；截图：`tests/screenshots/`。`tests/browser.acceptance.mjs` 导出一个接收 Playwright Page 的验收函数，使用独立浏览器上下文，不覆盖用户试玩存档。

## 设计与现阶段边界

详细设计见 `docs/天枢-游戏策划与设计文档-v1.0.md`。文档中的 18 张可收集行动卡、七天动态日程、独立室内地图和新结局演出属于后续规划；当前是四天首章内容、固定三张战术卡，以及同一校园场景的近景探索。

休息当前可重复恢复算力，目的是方便试玩，没有加入正式版时间成本。智力、声望、财富和精神目前主要承担成长反馈，尚未全部参与独立玩法判定。影像是既有原型中的本地参考占位，尚未制作完整角色表演、配音和口型；商业发布前需要替换或核验授权。

Blender 5.2 MCP 已在独立红色立方体工程中验收；本版三维校园由 Three.js 程序化生成，尚未使用 Blender 导出的 GLB 建筑。
