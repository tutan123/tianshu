# 天枢首章实施计划

**目标：** 交付独立可玩的本地 Web Demo。

**架构：** 延续现有数据驱动镜头与事件节点模式，将内容、可测试状态、交互渲染分离。素材放入当前版本 assets/，所有链接为相对路径。

**设计：** [design.md](design.md)

1. 内容和状态：先写节点解锁、重复结算、选项消耗、存档及结局规则测试；实现 content.js 与 state.js；运行 node --test tests/state.test.cjs。
2. 地图与演出：实现 index.html、styles.css、game.js，完成热点、镜头推进、选择、结果、关系、聊天、模块、存档、设置与轨迹面板。
3. 小游戏：实现 minigames.js，答题、QTE、取证解谜、战术回合均支持成功和保底分支，暂停保持计时，存档恢复不重复结算。
4. 资产集成：保存原创地图，复制所需本地参考视频并生成首帧；离线图标使用本地 lucide 库；新增 README 和启动入口。
5. 验证与修复：运行状态测试和 Playwright 全流程；逐个检查桌面和手机截图、无横向溢出、视频解码、资源缺失兜底、存读档；修复实际发现后重新验证。

当前目录没有 Git 仓库，使用新版本目录隔离旧原型，不新建提交。
