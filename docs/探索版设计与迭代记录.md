# 天枢：重返江大 / 探索版设计

## 定位

这是以重生校园故事为主的互动影游，探索和轻 RPG 成长是玩家主动改变故事的手段。参考《重生2》的“剧情节点 → 场景探索或小游戏 → 数值与分支反馈”循环，不照搬其人物、演出或整套关卡。

当前目标是可运行的首章纵向切片，不是把一张好看的地图当成完整游戏。

## 一次游玩的节奏

1. 在宿舍完成觉醒，建立陈旭与天枢的关系。
2. 在校园全景选择地点，切入自由行走；也可以直接进入已解锁的剧情。
3. 在建筑入口进入室内，沿走廊走入四个房间，接触具体的人和物。
4. NPC 提供生活信息、线索和当前剧情入口；电脑启动小游戏。
5. 宝箱与印章提供一次性收益，装备改变后续挑战。
6. 玩家回到主线，用新的能力、羁绊或证据影响选择，完成首章结局。

## 地图结构

### 室外

- 中央校园：钟楼、喷泉、宿舍群、图书馆、实验楼、运动场、维修铺。
- 镜湖：湖岸、桥、船屋、桥畔宝箱和石板支路。
- 西侧林间：弯曲步道、分岔补给、秋树、台阶与旧气象台台地。
- 花园口袋空间：低矮花池、树丛、矮篱、石头、围栏与隐藏铁盒。
- NPC 与调查点有实体模型和接近提示，非只有地图菜单。
- 点击地面会规划绕障路线；键盘和移动方向控件直接移动。

### 室内

| 区域 | 四个房间 | 核心内容 |
| --- | --- | --- |
| 梧桐宿舍 | 陈旭寝室、新生寝室、公共客厅、自习洗衣间 | 双层床、苏祁、旧主机、私人便签 |
| 钟楼教学楼 | 阶梯教室、研讨教室、教授办公室、校史展览室 | 教授与助教、课桌、黑板、竞赛线索 |
| 静川图书馆 | 文学阅览、数字资料、林晚阅读角、旧报刊档案 | 书架、林晚、信号复原终端 |
| 镜湖船屋 | 船具收藏、水文观测、临湖茶室、旧船坞仓库 | 独木舟、守湖人、旧物箱 |
| 风雨运动馆 | 体能训练、战术分析、更衣、器材保管 | 储物柜、训练垫、装备提示 |
| 知行实验楼 | 嵌入式实验、量子机房、仪器配电、封存档案 | 服务器、开关、需要通电的电子箱 |
| 后街维修铺 | 回收工坊、柜台补给、维修操作、旧物储藏 | 回收小游戏、装备与消耗品 |
| 学生会馆 | 广播站、社团活动、学生会办公室、校史资料库 | 印章交付与专注吊坠奖励 |

所有房间通过开敞门洞与走廊相连，不设置无法打开的装饰房门。宿舍附楼、维修铺东间入口目前复用对应建筑的室内区域，不冒充独立新关卡。

当前八处室内采用同一套四房间基础平面，按区域更换家具与内容。下一阶段应为教学楼增加阶梯教室层差、为宿舍增加长走廊、为图书馆增加环形书库，进一步减少布局重复。

## 探索玩法

### 校史寻踪

八个室内各有一枚校史印章。每枚提供 15 EXP。收集齐后到学生会馆交付，获得专注吊坠、300 现金、100 EXP、8 声望。任务不依赖主线选项，避免玩家因为先做支线而卡住。

### 实验楼电力

电子箱起初无法打开。教授和助教给出线索，玩家找到仪器室配电开关，启动后打开封存电子箱。开关与奖励都进入存档，重进房间不能刷奖励。

### 记忆物件

室外地点保留八件私人记忆收藏，各自提供小幅属性或羁绊变化。它们与八枚校史印章是两套收藏：前者塑造人物，后者引导走遍地图。

### 宝箱与补给

普通室内箱、林间补给、庭院铁盒提供少量现金、经验和咖啡。咖啡只能在非剧情挑战时使用，库存上限 9。重复检查显示空箱，不重复发放。

## RPG 成长

- 首章等级 1 至 8，经验上限 700。
- 手部、衣装、配件三个装备槽，不能在挑战中临时换装。
- 六件装备与两种消耗品。收益覆盖战斗攻击、格挡、生命，以及小游戏时间、精准窗口、回收速度、回收价值。
- 天枢模块、角色等级、装备是不同的成长来源，避免所有数值只来自一个按钮。
- 当前是轻量成长体验，未实现随机词条、套装、刷怪掉落或多角色编队。

## 小游戏

### 零件回收

参考回收式小游戏的摆动、发射、命中、负重回收循环。Matter.js 负责碰撞查询。芯片、电路板、线圈、废主机价值和重量不同，玩家可以放下重物。限时内达到 250 分首胜，后续可挑战纪录。

装备影响回收时间、速度与价值。首次成功提供 180 现金、60 EXP、10 算力；重复挑战不刷首胜资源。

### 信号复原

三轮信号顺序，长度分别为 3、4、5。玩家记忆闪烁顺序并输入，三次错误后结束。每轮可消耗算力重播一次，支付与进度进入存档。

### 已有剧情挑战

保留答题、时机判定、线路取证和战术卡牌对决。剧情失败仍推进故事，不把互动影游变成强制刷数值的关卡游戏。

## 演出与美术

- 室外使用 Three.js 实时 3D，支持昼夜、雨、湖水和角色运动。
- 钟楼是本项目在 Blender 中制作的原创模型。
- 家具、树木、草丛、花与岩石使用从官方渠道取得的 Kenney CC0 模型。来源与原许可证保存在 assets。
- 室内为去屋顶剖面，矮墙保留空间层次，门洞保留碰撞边界。
- 小地图是同一场景的第二台正交相机，不是装饰性缩略图。
- 全区地图按钮在局部跟随和俯视全图之间切换。
- 现有人物仍为风格化低多边形占位角色，未达到正式互动影游的人物制作规格。后续需统一主角建模、表情与演出素材。

## 架构与存档

- `content.js`：主线、支线、人物、对话和小游戏节点数据。
- `state.js`：剧情推进、数值、存档恢复与输入验证。
- `rpg.js`：等级、装备、消耗品与小游戏首胜记录。
- `exploration.js`：区域、互动对象、任务、一次性奖励和探索存档验证。
- `world-art.js`：离线模型实例、室内搭建、室外陈设与互动外观。
- `campus3d.js`：相机、渲染、移动、碰撞、路径、室内外切换。
- `salvage.js`：回收与记忆小游戏；`minigames.js` 保留原有挑战。
- `game.js`：剧情界面、探索对话、存档与各模块连接。

旧 3.0 存档缺少成长或探索字段时会补上默认值；已经领取的探索奖励、印章、开关和任务完成状态需要保留。当前不保存每一帧的行走坐标，刷新后回到校园总览。

## 本轮迭代

1. 视觉与成长：导入原创钟楼，改进界面、场景预览，加入装备商店与两种小游戏。
2. 地图与探索：八处室内、32 房间、NPC、终端、印章、宝箱、电力任务、林间支路与台地。
3. 动线与验收：检查出生点、家具占位、薄墙寻路、移动端方向盘与互动按钮。真实测试记录以 tests 下的结果为准。

## 后续值得做的内容

1. NPC 日程：同一个人早晨在教室、傍晚在球场，提供不同话题和观察线索。
2. 观察卡牌：从环境调查获得“旧发票”“监控盲区”等线索卡，用于交涉和取证，不只增加战斗伤害。
3. 伙伴协作：苏祁缩短终端处理时间，林晚提供文献线索；选择同行者会改变探索对话。
4. 可回溯小事件：玩家第一次失败后留下记忆标记，第二次能用情报而不是纯数值解决。
5. 教学楼停电章节：广播、应急灯、NPC 移动、终端和卡牌取证共同组成一段完整场景事件。

上述五项是后续设计，不是本轮已经实现的功能。
