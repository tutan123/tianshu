# 大地图与多楼层 3.4

## 本轮范围

延续用户指定的离线网页入口。保留旧校园和存档，将世界边界从 x[-57,42]、z[-36,37] 扩展为 x[-62,102]、z[-75,105]，平面包围面积约为原来的 4.1 倍。新增南门商店街、校外生活街区、东侧荷院与沿河步道。面积是可导航世界边界的面积，不代表扣除建筑和水面的净可走面积。

参考四川大学望江校区的功能分区、荷池周边院落与多层历史建筑气质；重新设计位置、道路、立面和建筑名称。参考资料不作为游戏纹理或模型导入。

- 官方历史布局资料：https://historytourism.scu.edu.cn/info/1035/3133.htm
- 官方校史展览馆介绍：https://archives.scu.edu.cn/info/1011/1295.htm

## 实现分工与接口

1. WorldDistricts：独立室外数据与几何模块，提供 bounds、buildings、build(root) -> {colliders,visuals}。加入七栋可进入的新建筑与街道、荷院、河岸陈设。由独立实现代理完成该模块及其几何测试。
2. CampusRooms：集中管理新增商铺、各建筑楼层、楼梯连接与专用室内。旧八处一层保留原有任务。教学楼/图书馆/校史馆三层，宿舍/书店/咖啡馆/工作室两层。各层独立陈设、线索和可拾取奖励。
3. 主流程集成：世界边界、相机、大小地图、区位导航、商店交易、楼梯进出和存档标识兼容。
4. 验收：真实浏览器跨区移动、新建筑进入、楼层往返、各层目标可达、交易、存档、桌面和手机截图及像素检查。补充单元测试后进行代码复查。

## 数据约定

新建筑 bookshop(-35,60)、cafe(-12,60)、grocery(12,60)、arcade(36,60)、clinic(-34,89)、studio(8,89)、museum(72,-27)。建筑入口统一由建筑描述的 entry 提供。历史八枚印章的集合不扩大；新增探索物件使用独立稳定 ID，不复用旧宝箱奖励。楼层切换仅通过可抵达楼梯触发，切换位置位于目标楼梯附近，离开建筑回到原入口。
