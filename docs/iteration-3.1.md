# 天枢 3.1：三轮迭代

## 参考研究

本轮直接阅读本地重生2分析的 07 小游戏、10 数值、12 地图，以及实际提取的 Hook.cs、MiniGameShuXin.cs。参考抓手的摆动/发射/回收状态、重量影响耗时、首通与重复奖励分离、装备效果统一计算和地图地点触发机制。实现采用天枢校园维修主题与原创表现。

## 第一轮：画面

修正 Three.js 旧色彩空间导致的发白；Blender 5.2 建模原创钟楼，通过结构化网格数据导入游戏；优化昼夜、材质、地面与建筑细节；地点卡使用对应三维场景实景截图；缩小地图首页冗余信息，增加探索与成长 HUD。

## 第二轮：玩法

新增 RPG 经验/等级、三个装备槽、可购买消耗品、探索收集品和一次性领取。装备真实影响伤害、格挡、QTE 窗口、小游戏时间和回收速度。新增“零件回收”抓手机制，采用 Matter.js 负责碰撞查询，摆动/发射/回收是确定性状态机。首通获得经验和物资，重玩只刷新纪录，避免无限刷取奖励。剧情失败保底继续。

## 第三轮：实测与平衡

通过实际浏览器验证素材、地图、购物、穿戴、探索领取、小游戏首通/重玩/暂停/刷新、剧情和移动端。对过亮光照、操作按钮拥挤、时间不足或奖励重复等问题逐项修复。保留可重跑测试和截图。

兼容旧 v3 存档，缺少 RPG 字段的进度迁移为默认角色数据。现有剧情、关系和存档槽延续。
